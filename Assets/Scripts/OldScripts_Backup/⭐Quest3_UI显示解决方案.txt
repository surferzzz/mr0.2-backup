选中 VRSimpleUI 对象，在 Inspector 中可以调整：

┌─────────────────────────────────────┐
│  VR Simple UI (Script)              │
│  ─────────────────────────────────  │
│  Distance From Camera:  2.0         │  ← 距离
│  UI Scale:              0.001       │  ← 大小
│                                     │
│  Hit Count:             0           │  ← 当前碰撞次数
│  Last Hit Object:       无          │  ← 最后碰撞对象
└─────────────────────────────────────┘

调整建议：
• Distance: 1.5 - 3.0 米（太近会模糊，太远看不清）
• UI Scale: 0.0008 - 0.0015（调整UI大小）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: 在 Quest 3 中还是看不到 UI？
A1: 检查：
    1. 场景中是否有 VRSimpleUI 对象？
    2. 是否点击播放按钮 ▶️？
    3. 尝试调整 Distance From Camera（增加到 3）

Q2: UI 太小/太大？
A2: 选中 VRSimpleUI，调整 UI Scale：
    • 太小：增加到 0.002
    • 太大：减少到 0.0005

Q3: UI 不跟随视角？
A3: 确保场景中有 Main Camera
    VRSimpleUI 会自动查找 Camera.main

Q4: UI 显示 "等待检测..." 不更新？
A4: 确保目标对象有 SuperSimpleCollisionTest 脚本
    并且碰撞确实发生了

Q5: 能否显示更多信息？
A5: 可以！编辑 VRSimpleUI.cs 中的 UpdateText() 方法
    添加您想显示的任何信息
