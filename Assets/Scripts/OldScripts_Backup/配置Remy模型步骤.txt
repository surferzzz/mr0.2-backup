第1步：清理自动创建的测试模型
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在 Hierarchy 中找到并删除这些对象：

1. 找到 "Patient" 对象（自动创建的测试模型）
2. 右键点击 → Delete（删除）
3. 找到 "TestBall" 对象
4. 右键点击 → Delete（删除）

这样就清理掉了测试对象。

第2步：在 Hierarchy 中找到您的 Remy 模型
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在右侧的 Hierarchy 窗口中：

• Hierarchy
  ├─ Main Camera
  ├─ Directional Light
  ├─ outpost with snow
  ├─ PlayerController
  ├─ Remy@Laying Seizure    ← 👆 找到这个！
  └─ ...

点击选中 "Remy@Laying Seizure"


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第3步：配置为可按压患者
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

选中 Remy 后，有两种方法：

方法A - 使用顶部菜单（推荐）：
  1. Unity 顶部菜单 → CPR训练系统
  2. 点击 "🎯 配置现有模型为患者"
  3. 等待配置完成（3秒）

方法B - 使用右键菜单：
  1. 在 Hierarchy 中右键点击 "Remy@Laying Seizure"
  2. 选择 "CPR设置"
  3. 点击 "⚡ 配置选中模型为可按压患者"
  4. 等待配置完成（3秒）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第4步：检查配置结果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

配置完成后，在 Hierarchy 中展开 Remy：

• Remy@Laying Seizure
  ├─ ...（原有的骨骼结构）
  └─ ChestArea        ← 新增！绿色胸部检测区

在 Scene 视图中，您应该看到：
• Remy 模型的胸部位置有一个半透明的绿色方块
• 这就是按压检测区


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第5步：调整胸部检测区位置（重要！）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

因为 Remy 是躺着的姿势，需要调整绿色方块到正确的胸部位置：

1. 在 Hierarchy 中展开 "Remy@Laying Seizure"
2. 找到并选中 "ChestArea" 子对象
3. 在 Scene 视图中，用移动工具（W键）拖动绿色方块
4. 放到 Remy 胸部中央位置（两乳头连线中点）

或者在 Inspector 中手动调整：
• Transform → Position
• 调整 X, Y, Z 坐标
• 直到绿色方块在胸部正确位置


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第6步：测试按压功能（编辑器中）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在部署到 Quest 3 之前，先在编辑器中测试：

1. 打开 CPR 控制面板（顶部菜单 → CPR训练系统 → 打开控制面板）
2. 向下滚动，点击 "🎾 创建测试球体"
3. 调整测试球位置（在 Remy 胸部上方）
4. 点击 Unity 播放按钮 ▶️
5. 观察：
   • 球体掉落到 Remy 胸部
   • UI 显示按压数据
   • Console 显示检测日志

如果球体位置不对：
• 停止播放
• 在 Hierarchy 中选中 TestBall
• 调整 Transform → Position，移到 Remy 上方
• 重新播放测试

第7步：配置 XR Tools 手部（Quest 3）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

要让 Quest 3 的手部能够按压，需要确保手部有碰撞器：

【检查 XR 手部设置】

1. 在 Hierarchy 中找到您的 XR Rig / XR Origin：
   • XRRig
     ├─ Camera Offset
     │  ├─ Main Camera
     │  ├─ LeftHand Controller   ← 检查这个
     │  └─ RightHand Controller  ← 检查这个

2. 选中 LeftHand Controller
3. 在 Inspector 中查看是否有：
   • Collider（碰撞器）
   • Rigidbody（刚体）

4. 如果没有，添加碰撞器：
   • Inspector 底部 → Add Component
   • 搜索 "Sphere Collider"
   • 添加
   • 设置 Radius = 0.05

5. 添加 Rigidbody：
   • Add Component → Rigidbody
   • 取消勾选 "Use Gravity"
   • 勾选 "Is Kinematic"

6. 对 RightHand Controller 重复同样操作


【自动配置手部（推荐）】

或者使用自动配置：

1. 在 CPR 控制面板中
2. 找到 "🔧 问题修复" 区域
3. 点击 "⚡ 修复所有Quest 3问题"
4. 系统会自动配置手部碰撞

第8步：部署到 Quest 3
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【前提条件】
✅ 已安装 Meta XR SDK
✅ 已切换到 Android 平台
✅ Quest 3 已连接并允许 USB 调试

【构建步骤】

1. File → Build Settings
2. 确认 "Android" 已选中
3. 点击 "Build And Run"
4. 选择保存位置，输入文件名
5. 等待构建完成（3-5分钟）
6. 应用自动安装到 Quest 3

第9步：在 Quest 3 中测试
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3. 看到绿色的胸部区域
4. 用手触碰绿色区域
5. 观察：
   • 眼前的 UI 会显示按压数据
   • 按压次数实时增加
   • 深度进度条实时更新

💡 重要提示
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. **删除测试对象**
   一定要先删除 "Patient" 和 "TestBall"，
   否则测试球会掉在错误的模型上

2. **调整胸部位置**
   Remy 是躺着的，ChestArea 可能需要手动调整位置

3. **手部碰撞器**
   XR Tools 的手部必须有 Collider 和 Rigidbody
   才能触发按压检测

4. **UI 位置**
   UI 会自动附着在摄像机上，跟随您的视角
   在 VR 中会显示在您眼前

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: 配置后看不到绿色方块？
A1: 在 Hierarchy 中选中 ChestArea → 按 F 键聚焦

Q2: Quest 3 中手穿过去了，没有检测？
A2: 检查 XR 手部是否有 Collider 和 Rigidbody
    或在控制面板点击 "⚡ 修复所有Quest 3问题"

Q3: UI 在 VR 中看不到？
A3: UI 应该在您眼前，尝试抬头或低头寻找
    或调整 SimplePressUI 的 uiScale 参数

Q4: 按压没有反应？
A4: 检查：
    • ChestArea 是否在正确位置
    • 手部是否有碰撞器
    • Console 是否有错误信息
