1️⃣ Hierarchy 右键 → 3D Object → Cube
   命名为 "TestTarget"

2️⃣ Inspector 中设置：
   Position: (0, 1, 0)

3️⃣ Add Component → Rigidbody
   ☐ Use Gravity（取消勾选）
   ☑ Is Kinematic（勾选）

4️⃣ Add Component → 搜索 "SimpleDemo_Step1"
   添加这个脚本

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ Hierarchy 右键 → 3D Object → Sphere
   命名为 "TestBall"

2️⃣ Inspector 中设置：
   Position: (0, 2, 0)（在方块上方）

3️⃣ Add Component → Rigidbody
   ☑ Use Gravity（勾选）

2️⃣ 观察：
   ✅ 球掉落
   ✅ 碰到方块
   ✅ 方块从绿色变成红色
   ✅ Console 显示："🎯 碰撞检测！第 1 次"

看到了吗？✨ 成功！


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第4步：移到 Remy 身上（3分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ Hierarchy → 选中 Remy@Laying Seizure
   右键 → 3D Object → Cube
   命名为 "ChestTarget"

2️⃣ 在 Scene 视图中：
   按 W 键（移动工具）
   拖动方块到 Remy 的胸部位置

3️⃣ Inspector 中设置：
   Scale: (0.3, 0.1, 0.2)

4️⃣ Add Component → Rigidbody
   ☐ Use Gravity（取消）
   ☑ Is Kinematic（勾选）

5️⃣ Add Component → SimpleDemo_Step1

6️⃣ 调整 TestBall 位置到 ChestTarget 上方

7️⃣ 点击播放 ▶️ 测试

✅ 成功！Remy 的胸部可以检测碰撞了！
