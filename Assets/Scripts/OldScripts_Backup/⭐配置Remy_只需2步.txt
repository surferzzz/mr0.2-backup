⚠️ Quest 3 手部检测注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

要让 Quest 3 的手部能触发按压，需要确保：

1. **XR 手部有碰撞器**
   您的 XR Tools 手部对象需要：
   • Collider（碰撞器）
   • Rigidbody（刚体）

2. **自动配置手部**
   在 CPR 控制面板中：
   • 找到 "🔧 问题修复" 区域
   • 点击 "⚡ 修复所有Quest 3问题"
   • 系统会自动配置手部碰撞

3. **手动配置手部**
   如果自动配置不行，手动添加：
   
   在 Hierarchy 中找到手部对象（如 LeftHandAnchor）：
   • Add Component → Sphere Collider
   • Radius = 0.05
   • Add Component → Rigidbody
   • 取消勾选 Use Gravity
   • 勾选 Is Kinematic

如果自动放置的绿色方块位置不完美：

1. Hierarchy → 展开 Remy@Laying Seizure
2. 选中 ChestArea
3. 在 Scene 视图中按 W 键（移动工具）
4. 拖动绿色方块到正确的胸部位置
5. 或在 Inspector 中手动调整 Position

推荐位置：
• Remy 躺着时，胸部在身体中央偏上
• 两乳头连线的中点

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: 菜单中没有 "配置 Remy 模型为患者"？
A1: 等待 Unity 编译完成（底部进度条）
    或者使用 "🎯 配置现有模型为患者"，效果一样

Q2: 绿色方块看不到？
A2: Hierarchy → 选中 ChestArea → 按 F 键聚焦

Q3: Quest 3 中手穿过去了？
A3: 手部需要碰撞器！
    • 控制面板 → ⚡ 修复所有Quest 3问题
    • 或手动给手部添加 Collider

Q4: UI 在 VR 中看不到？
A4: • UI 在您正前方，抬头或低头找找
    • 检查 Hierarchy 中是否有 SimplePressUI_Canvas

Q5: 测试球掉不到 Remy 上？
A5: • 调整 TestBall 的 Position
    • 确保球在 Remy 正上方
    • Y 坐标要比 Remy 高
