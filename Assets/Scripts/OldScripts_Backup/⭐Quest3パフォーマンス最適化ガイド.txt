🔴 問題：Quest 3で動作がカクカクする

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📋 原因チェックリスト
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ] 画質設定が高すぎる（High/Ultra）
[ ] 影がオンになっている
[ ] 複雑な3Dモデルが多い
[ ] UI更新頻度が高すぎる
[ ] ライトが多すぎる
[ ] 物理演算が重い

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ⚡ 即座の解決方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【方法1】一键自動最適化（推奨！）
───────────────────────────────────────────
Unityで：
  CPR訓練システム → ⚡ Quest 3 パフォーマンス最適化

  ↓ クリックすると自動で以下を実行：
  ✅ 画質設定を「Low」に変更
  ✅ 影をオフ
  ✅ V-Syncをオフ
  ✅ アンチエイリアシングをオフ
  ✅ すべてのオブジェクトを最適化
  ✅ UIとライティングを最適化

【方法2】手動最適化
───────────────────────────────────────────
① 画質設定：
   Edit → Project Settings → Quality
   - Android用のレベルを「Low」に設定

② 影をオフ：
   Edit → Project Settings → Quality
   - Shadows: Disable

③ Player設定：
   Edit → Project Settings → Player → Other Settings
   - Color Space: Linear → Gamma（軽量化）
   - Graphics API: Vulkan（推奨）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  🎯 シーン内で確認すべきこと
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ライトの数を確認
   ───────────────────────────────────────
   Hierarchy → 右クリック → 3D Object → Light
   
   推奨：
   ✅ Directional Light: 1個のみ
   ❌ Point/Spot Light: なるべく削除

2. 3Dモデルのポリゴン数
   ───────────────────────────────────────
   Remyモデルを選択 → Inspector → ポリゴン数確認
   
   目安：
   ✅ 10,000ポリゴン以下: 最適
   ⚠️ 10,000-50,000: やや重い
   ❌ 50,000以上: 重い → LOD設定推奨

3. Sci-Fiアセット
   ───────────────────────────────────────
   「Sci-Fi Styled Modular Pack」が重い可能性

   対策：
   ① 不要なオブジェクトを削除
   ② オブジェクトを減らす
   ③ シンプルな背景に変更

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  🔧 具体的な最適化手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【ステップ1】自動最適化を実行
───────────────────────────────────────────
CPR訓練システム → ⚡ Quest 3 パフォーマンス最適化
↓
「実行」をクリック


【ステップ2】シーンを保存
───────────────────────────────────────────
Ctrl + S


【ステップ3】Build And Run
───────────────────────────────────────────
File → Build Settings → Build And Run


【ステップ4】Quest 3で確認
───────────────────────────────────────────
① FPSモニターを確認
② カクつきがなくなったか確認


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📊 パフォーマンスモニター追加
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

リアルタイムでFPSを確認したい場合：

① Hierarchyで空のGameObjectを作成
② Inspectorで「Add Component」
③ 「Quest3PerformanceMonitor」を追加
④ Build And Run

→ Quest 3でFPS/メモリ使用量が表示されます


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  🎯 Quest 3の目標FPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 理想: 72fps（Quest 3の標準リフレッシュレート）
⚠️ 最低: 60fps（これ以下は酔いやすい）
❌ 危険: 45fps以下（即座に最適化必要）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ⚠️ よくある問題と解決策
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

問題1: 影がちらつく
───────────────────────────────────────────
解決: 影を完全にオフにする
   → 自動最適化ツールで解決


問題2: UIがカクカクする
───────────────────────────────────────────
解決: VRSimpleUI_Optimizedを使用
   ① 現在のVRSimpleUIを削除
   ② 新しいGameObjectを作成
   ③ VRSimpleUI_Optimizedコンポーネントを追加


問題3: 手の追跡が遅延する
───────────────────────────────────────────
解決: Rigidbodyの設定を確認
   ① 手のRigidbody → Collision Detection: Discrete
   ② Interpolate: None


問題4: Remyモデルが重い
───────────────────────────────────────────
解決: スキニング品質を下げる
   ① Remyを選択
   ② Inspector → Skinned Mesh Renderer
   ③ Quality: Bone2（最軽量）


問題5: 背景が複雑すぎる
───────────────────────────────────────────
解決: Sci-Fiアセットを減らす
   ① Hierarchyで不要なオブジェクトを削除
   ② または簡素な背景に変更
