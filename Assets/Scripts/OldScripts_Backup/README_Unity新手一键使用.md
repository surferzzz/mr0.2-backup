## 🎯 具体使用步骤（图文教程）

### 步骤1：创建CPR系统（30秒）

**方法A：使用菜单**
```
1. 点击 Unity顶部菜单 → CPR训练系统
2. 点击 "🚀 一键创建完整系统"
3. 等待控制台显示 "✅ CPR系统设置完成"
4. 完成！
```

**方法B：使用控制面板**
```
1. 点击 Unity顶部菜单 → CPR训练系统 → 📋 打开控制面板
2. 在控制面板中点击 "✨ 一键创建完整系统"
3. 等待控制台显示成功消息
4. 完成！
```

**创建后场景中会有：**
- ✅ Patient（患者模型）
- ✅ SystemManager（系统管理器）
- ✅ SimplePressUI（UI管理器）
- ✅ SimplePressUI_Canvas（UI画布）
- ✅ VRHandSetup（VR手部设置）
- ✅ CPRSetup（总控制对象）

### 步骤2：测试系统（1分钟）

**在Unity编辑器中测试：**

```
1. 点击菜单：CPR训练系统 → 🧪 测试工具 → 🎾 创建测试球体
2. 点击Unity顶部的播放按钮 ▶️（Play）
3. 观察：
   - 球体掉落
   - 触碰绿色胸部区域
   - UI实时显示按压数据
   - Console显示检测信息
4. 点击播放按钮停止测试
```

**在Quest 3设备上测试：**

```
1. 确保Quest 3通过USB连接到电脑
2. 点击菜单：File → Build Settings
3. Platform选择：Android
4. 点击：Build And Run
5. 等待Build完成并自动安装
6. 戴上Quest 3头显
7. 用手触碰绿色胸部区域
8. 观察UI数据更新
```

### 步骤3：切换场景（10秒）

**使用菜单切换：**

```
1. 点击：CPR训练系统 → 🎬 场景切换
2. 选择一个场景，例如：🚗 车祸现场
3. 场景会自动切换并创建环境
4. 完成！
```

**使用控制面板切换：**

```
1. 打开控制面板
2. 在 "🎬 场景切换" 区域
3. 点击任意场景按钮
4. 完成！
```

**可用场景：**
- 📚 **标准训练** - 简洁的训练环境
- 🚗 **车祸现场** - 有道路、车辆残骸、交通噪音
- ⚡ **地震灾害** - 有废墟、碎片、昏暗灯光
- 🏠 **家庭意外** - 有家具、温馨环境
- 🏢 **公共场所** - 有围观人群、公共空间

### 步骤4：修复问题（如果需要）

**如果Console有很多红色错误：**

```
1. 点击菜单：CPR训练系统 → 🔧 修复Quest 3问题
2. 等待Console显示 "✅ 所有问题已修复"
3. 完成！
```

**或者使用控制面板：**

```
1. 打开控制面板
2. 在 "🔧 问题修复" 区域
3. 点击 "⚡ 修复所有Quest 3问题"
4. 完成！
```

**其他修复工具：**
- 📊 **诊断当前问题** - 详细检查哪里有问题
- ♻️ **快速重启系统** - 清理并重建整个系统
- 🧹 **清理错误日志** - 清空Console的错误信息

### 关键位置

1. **顶部菜单栏**
   - 位置：Unity窗口最顶部
   - 包含：File, Edit, Assets, GameObject, Component, **CPR训练系统**, Window, Help

2. **播放按钮 ▶️**
   - 位置：工具栏左侧
   - 功能：进入/退出播放模式测试

3. **Hierarchy（层级视图）**
   - 位置：通常在左侧
   - 显示：场景中的所有对象
   - 创建后您会看到：Patient, SystemManager, SimplePressUI等

4. **Scene（场景视图）**
   - 位置：通常在中间
   - 显示：3D场景，可以看到患者模型

5. **Inspector（检查器）**
   - 位置：通常在右侧
   - 显示：选中对象的属性
   - 可以调整各种参数

6. **Console（控制台）**
   - 位置：通常在底部
   - 显示：日志、警告、错误信息
   - 操作成功会显示 ✅ 消息

## 🎓 Unity基础操作

### 场景视图操作

```
鼠标操作：
- 右键拖动：旋转视角
- 中键拖动：平移视角
- 滚轮：缩放视角
- 左键点击：选择物体

键盘操作：
- F键：聚焦到选中物体
- W键：移动工具
- E键：旋转工具
- R键：缩放工具
```

### 对象操作

```
选择对象：
1. 在Hierarchy中点击对象名称
2. 或在Scene视图中直接点击物体

移动对象：
1. 选中对象
2. 按W键（移动工具）
3. 拖动3D箭头移动

删除对象：
1. 选中对象
2. 按Delete键
3. 或右键 → Delete
```

### 播放模式

```
进入播放模式：
- 点击顶部的播放按钮 ▶️
- 或按快捷键 Ctrl+P (Win) / Cmd+P (Mac)

退出播放模式：
- 再次点击播放按钮
- 或按快捷键 Ctrl+P / Cmd+P

注意事项：
⚠️ 播放模式中的修改不会保存！
⚠️ 停止播放后所有改动会还原！
```

## 🎮 Quest 3设备使用

### Build设置（第一次需要）

```
1. 点击菜单：File → Build Settings
2. Platform列表中找到：Android
3. 点击 "Switch Platform"（如果需要）
4. 等待切换完成（可能需要几分钟）
5. 点击 "Player Settings..."
6. 设置：
   - Company Name: 填写您的名字
   - Product Name: CPR Training
   - Minimum API Level: Android 10.0
7. 点击 "XR Plug-in Management"
8. 勾选 Android → Oculus
9. 关闭设置窗口
```

### Build到Quest 3

```
1. 用USB线连接Quest 3到电脑
2. 戴上头显，允许USB调试
3. Unity中点击：File → Build Settings
4. 点击 "Build And Run"
5. 选择保存位置（或直接点确定）
6. 等待Build完成（第一次较慢）
7. 自动安装到Quest 3
8. 摘下头显，等待安装完成提示
9. 戴上头显，开始测试！
```

### Quest 3测试

```
应该看到：
✅ 前方有黑色半透明UI面板
✅ UI显示 "CPR训练系统"
✅ 患者躺在前方
✅ 胸部区域是绿色的

应该能做：
✅ 用手触碰绿色胸部
✅ 看到UI数据实时更新
✅ 质量指示器变色（红/黄/绿）
✅ 听到反馈声音（如果有）
```

## 🆘 常见问题解决

### Q1: 找不到"CPR训练系统"菜单？

**A:** 等待Unity编译完成
```
1. 查看Unity底部进度条
2. 等待 "Compiling..." 消失
3. 刷新编辑器：Ctrl+R (Win) / Cmd+R (Mac)
4. 如果还没有，检查脚本是否在正确位置
```

### Q2: 点击按钮没反应？

**A:** 查看Console
```
1. 打开Console面板（Window → General → Console）
2. 查看是否有错误信息
3. 如果有红色错误，点击菜单：
   CPR训练系统 → 🔧 修复Quest 3问题
```

### Q3: 创建的对象看不见？

**A:** 调整视角
```
1. 在Hierarchy中选中 "Patient"
2. 按F键聚焦到对象
3. 或在Scene视图中用鼠标调整视角
```

### Q4: Console有很多红色错误？

**A:** 自动修复
```
方法1: 菜单 → CPR训练系统 → 🔧 修复Quest 3问题
方法2: 控制面板 → 问题修复 → ⚡ 修复所有Quest 3问题
方法3: 清理日志 → 控制面板 → 🧹 清理错误日志
```

### Q5: Quest 3看不到UI？

**A:** 运行修复工具
```
1. 菜单 → CPR训练系统 → 🔧 修复Quest 3问题
2. 等待修复完成
3. 重新Build到Quest 3
```

### Q6: 手穿过胸部？

**A:** 设置VR手部
```
1. 菜单 → CPR训练系统 → 🧪 测试工具 → 🤚 设置VR手部
2. 或：菜单 → 🔧 修复Quest 3问题（会自动设置）
```

### Q7: 想重新开始？

**A:** 清理并重建
```
1. 菜单 → CPR训练系统 → 🧹 清理所有对象
2. 确认删除
3. 菜单 → CPR训练系统 → 🚀 一键创建完整系统
4. 完成！
```
