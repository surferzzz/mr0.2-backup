步骤：

1️⃣ 打开 CPR 控制面板
   ├─ 位置：Unity 编辑器右侧窗口
   └─ 标题：📋 CPR训练系统控制面板

2️⃣ 向下滚动，找到 "🧪 测试工具" 区域

3️⃣ 点击按钮：🎾 创建测试球体
   └─ 会在场景中创建一个橙色球体

4️⃣ 点击 Unity 顶部的播放按钮 ▶️

5️⃣ 观察效果：
   ├─ 球体会掉落到胸部上
   ├─ Console 显示检测日志
   ├─ UI 显示按压数据
   └─ 按压次数会增加

6️⃣ 再次点击播放按钮 ⏸️ 停止测试

✅ 如果看到数据更新 → 系统工作正常！

前提条件：
✓ 有 Quest 3 头显
✓ 有 USB-C 数据线
✓ Quest 3 电量充足

步骤：

【第1步】安装 Meta XR SDK
┌─────────────────────────────────────────────────────────────┐
│ 1. Unity 顶部菜单 → Window → Package Manager               │
│ 2. 左上角 '+' 按钮 → Add package by name                   │
│ 3. Name: com.meta.xr.sdk.core                              │
│ 4. 点击 'Add'                                              │
│ 5. 等待安装（1-2分钟）                                     │
│ 6. 安装完成后，关闭 Package Manager                        │
└─────────────────────────────────────────────────────────────┘

【第2步】切换到 Android 平台
┌─────────────────────────────────────────────────────────────┐
│ 1. File → Build Settings                                   │
│ 2. 选择 'Android' 平台                                     │
│ 3. 点击 'Switch Platform'                                  │
│ 4. 等待切换完成（首次 5-10 分钟）                          │
│                                                            │
│ ⚠️ 注意：首次切换会很慢，这是正常的！                       │
│          去喝杯咖啡，等待进度条完成 ☕                      │
└─────────────────────────────────────────────────────────────┘

【第3步】配置 Quest 3
┌─────────────────────────────────────────────────────────────┐
│ 1. USB-C 线连接 Quest 3 到电脑                             │
│ 2. 戴上 Quest 3 头显                                       │
│ 3. 头显中会弹出提示                                        │
│ 4. 选择 "允许 USB 调试"                                    │
│ 5. 勾选 "总是允许这台电脑"                                 │
│ 6. 点击 "确定"                                             │
└─────────────────────────────────────────────────────────────┘

【第4步】构建并运行
┌─────────────────────────────────────────────────────────────┐
│ 1. 在 Unity 中：File → Build Settings                      │
│ 2. 确认 'Android' 已选中                                   │
│ 3. 点击 'Build And Run' 按钮                               │
│ 4. 选择保存位置（如：桌面）                                │
│ 5. 输入文件名（如：CPR_Training）                          │
│ 6. 点击 "保存"                                             │
│ 7. 等待构建完成（3-5 分钟）                                │
│ 8. 应用会自动安装到 Quest 3                                │
└─────────────────────────────────────────────────────────────┘

【第5步】在 VR 中体验
┌─────────────────────────────────────────────────────────────┐
│ 1. 应用自动启动（或在 Quest 3 库中找到）                   │
│ 2. 您会看到：                                              │
│    ├─ 躺着的患者模型                                       │
│    ├─ 绿色的胸部区域                                       │
│    └─ 眼前的 UI 显示面板                                   │
│                                                            │
│ 3. 伸出手，触碰绿色胸部                                    │
│ 4. 观察：                                                  │
│    ├─ 按压次数增加                                         │
│    ├─ 深度显示（进度条）                                   │
│    ├─ 质量评估（颜色指示）                                 │
│    └─ Console 日志更新                                     │

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: 我点了播放按钮，但什么都没发生？
A1: 先创建测试球体！在控制面板点击 "🎾 创建测试球体"

Q2: 球体掉下去了，但没有检测到按压？
A2: 在控制面板点击 "⚡ 修复所有Quest 3问题"，然后重试

Q3: 看不到 UI 显示？
A3: 检查 Hierarchy 中是否有 "SimplePressUI_Canvas"
    如果没有，在控制面板重新点击 "✨ 一键创建完整系统"

Q4: Quest 3 连接不上？
A4: 1. 检查 USB 线是否插好
    2. Quest 3 中是否允许了 USB 调试
    3. 电脑是否安装了 Quest 驱动程序

Q5: Build 失败？
A5: 1. 确认已切换到 Android 平台
    2. 确认已安装 Meta XR SDK
    3. 在控制面板点击 "⚡ 修复所有Quest 3问题"
