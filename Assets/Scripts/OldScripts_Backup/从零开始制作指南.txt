【1.1 创建一个简单的方块】

1. Hierarchy 右键 → 3D Object → Cube
2. 命名为 "TestTarget"（测试目标）
3. 在 Scene 视图中调整位置：
   • Position: (0, 1, 0)
   • 放在 Remy 附近，容易看到的地方

【1.2 添加物理组件】

选中 TestTarget，在 Inspector 中：

1. 确认有 Box Collider（默认有）
2. Add Component → Rigidbody
3. Rigidbody 设置：
   ☑ Use Gravity = false（取消重力）
   ☑ Is Kinematic = true（勾选）

【1.3 添加检测脚本】

选中 TestTarget，在 Inspector 中：

1. Add Component → 搜索 "SimpleDemo_Step1"
2. 添加这个脚本
3. 在脚本参数中：
   • Hit Color = Red（红色）
   • Normal Color = Green（绿色）

【1.4 创建测试球】

1. Hierarchy 右键 → 3D Object → Sphere
2. 命名为 "TestBall"
3. 在 Inspector 中：
   • Position: 比 TestTarget 高一点
   • 例如: (0, 2, 0)
4. 确认有 Sphere Collider
5. Add Component → Rigidbody
6. Rigidbody 设置：
   ☑ Use Gravity = true（勾选重力）
   • Mass = 1

【1.5 测试！】

1. 点击 Unity 播放按钮 ▶️
2. 观察：
   ✅ TestBall 掉落
   ✅ 碰到 TestTarget
   ✅ TestTarget 变成红色
   ✅ Console 显示：🎯 碰撞检测！第 1 次

如果看到这些 → 成功！✨

如果没有 → 停下来，我们一起找问题

【2.1 在 Remy 上创建检测区】

1. Hierarchy → 选中 Remy@Laying Seizure
2. 右键 → Create Empty
3. 命名为 "ChestTarget"
4. 调整位置到 Remy 的胸部：
   • 在 Scene 视图中用移动工具(W键)拖动
   • 或手动设置 Position

【2.2 给检测区添加形状】

选中 ChestTarget，在 Inspector 中：

1. Add Component → Box Collider
2. Box Collider 设置：
   • Size: (0.3, 0.1, 0.2)
3. Add Component → Rigidbody
4. Rigidbody 设置：
   ☑ Is Kinematic = true
   ☐ Use Gravity = false

【2.3 添加视觉标识】

选中 ChestTarget：

1. Add Component → Mesh Filter
2. Mesh = Cube
3. Add Component → Mesh Renderer
4. 在 Materials 中创建一个绿色半透明材质

【2.4 添加检测脚本】

选中 ChestTarget：

1. Add Component → SimpleDemo_Step1
2. 设置颜色：
   • Normal Color = Green
   • Hit Color = Red

【2.5 测试！】

1. 调整 TestBall 位置到 ChestTarget 上方
2. 点击播放 ▶️
3. 观察：
   ✅ 球掉到 ChestTarget 上
   ✅ ChestTarget 变红
   ✅ Console 显示碰撞

成功！现在 Remy 的胸部有检测了！

Q: 球穿过去了，没有碰撞？
A: 检查：
   1. 两个对象都有 Collider？
   2. 至少一个有 Rigidbody？
   3. Is Trigger 是否取消勾选？

Q: Console 没有显示碰撞信息？
A: 检查：
   1. SimpleDemo_Step1 脚本是否添加？
   2. Console 是否被过滤了？（清除过滤）

Q: 看不到颜色变化？
A: 检查：
   1. 对象有 Renderer 吗？
   2. Normal Color 和 Hit Color 是否不同？
