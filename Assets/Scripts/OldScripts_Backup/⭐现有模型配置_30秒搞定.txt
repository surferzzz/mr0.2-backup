【快速测试 - 30秒】

1️⃣ Unity 顶部菜单 → CPR训练系统 → 📋 打开控制面板

2️⃣ 向下滚动，找到橙色按钮：🎾 创建测试球体

3️⃣ 点击 Unity 播放按钮 ▶️

4️⃣ 观察效果：
   • 球体掉落
   • 触碰胸部
   • UI 显示按压数据 ✨


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 配置后会自动创建
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

查看 Hierarchy，您会看到：

• Hierarchy
  ├─ 👤 您的人物模型
  │  └─ 🟢 ChestArea          ← 绿色按压检测区（新增）
  ├─ ⚙️ SystemManager         ← 数据管理（自动创建）
  ├─ 🎨 SimplePressUI         ← UI管理（自动创建）
  ├─ 📊 SimplePressUI_Canvas  ← UI画布（自动创建）
  └─ 🤚 VRHandSetup           ← VR手部（自动创建）


在 Scene 视图中：
• 人物模型胸部会有一个半透明的 🟢 绿色方块
• 这就是按压检测区！


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 UI 会显示什么？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

当按压胸部时，屏幕上会实时显示：

    ╔════════════════════════════════════╗
    ║  CPR 按压训练系统                  ║
    ╠════════════════════════════════════╣
    ║                                    ║
    ║  按压次数: 12 次                   ║
    ║  当前深度: 0.048m (4.8cm)          ║
    ║  平均深度: 0.045m (4.5cm)          ║
    ║                                    ║
    ║  深度进度: ████████░░ 48%          ║
    ║                                    ║
    ║  按压质量: 🟢 良好                 ║
    ║  状态: 按压中                      ║
    ║                                    ║
    ╚════════════════════════════════════╝

质量自动评估：
🟢 绿色 = 良好 (2-6cm)
🔴 红色 = 太浅 (<2cm)
🟠 橙色 = 太深 (>6cm)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔧 可选：调整胸部位置
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果绿色方块位置不对：

1. Hierarchy → 展开您的人物模型 → 选中 ChestArea
2. Inspector → Transform → 调整 Position
3. 或在 Scene 视图中直接拖动绿色方块

❓ 找不到菜单？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果 Unity 顶部没有 "CPR训练系统" 菜单：

1. 等待 Unity 底部进度条完成（正在编译）
2. 编译完成后菜单会自动出现
3. 如果还是没有，重启 Unity


或者使用右键菜单：

1. Hierarchy → 右键点击您的人物模型
2. 选择 "CPR设置" → "⚡ 配置选中模型为可按压患者"
