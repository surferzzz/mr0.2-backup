━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Unity编辑器测试：

1. 菜单 → CPR训练系统 → 🧪 测试工具 → 🎾 创建测试球体
2. 点击Unity顶部的播放按钮 ▶️
3. 观察：
   - 球体从上方掉落
   - 触碰绿色胸部区域
   - Console显示检测信息
   - UI数据实时更新
4. 点击播放按钮停止测试

Quest 3设备测试：

1. USB连接Quest 3到电脑
2. 戴上头显，允许USB调试
3. File → Build Settings → Build And Run
4. 等待Build和安装
5. 在VR中：
   - 用手触碰绿色胸部
   - 看到UI数据更新
   - 质量指示器变色
