## 0. 实验设计（问卷结构由此决定）

| 項目 | 設定 |
|---|---|
| 条件 A | 画面の表示だけ（深さ・速さを HUD に表示、グローブの振動 OFF） |
| 条件 B | 画面の表示＋手の振動（浅い／ちょうどよい／深すぎ の強さの違い、リズム振動、AED の通電感） |
| 设计 | **被験者間（between-subjects）**：1 人は A か B のどちらか一方だけを体験する |
| 参加者 | **50 人（各群 25 人）** |
| 割付 | **CPR 経験の有無で層別**し、各層の中で A 群・B 群に半々ランダム |
| 質問紙 | **体験後の 1 本だけ**。事前アンケートは廃止した |

### 事前アンケートを廃止した帰結

**失ったもの**：自己効力感の変化量（事前→事後）が出せない。
「訓練で自信が上がったか」という結果は、この研究では報告できない。

**失っていないもの**：自己効力感の**群間比較**は成立する。無作為割付なので
両群のベースラインは期待値として等しく、体験後の水準を比べれば群の差は読める。

**地味に痛いところ**：ANCOVA の共変量としてベースライン自己効力感が使えない。
残る共変量は CPR 経験（EXP0）と VR 経験（V1）で、結果との相関は
ベースライン自己効力感ほど高くないのが普通なので、誤差分散の減り方は小さくなる。
下の「②」で見込める検出力の改善は、ベースラインがある場合より控えめに考えること。

### 参加者 50 人（各群 25 人）でできること

両側 α=.05・検出力 0.8 を基準にすると：

| 効果量 d | 必要な人数／群 | **各群 25 人での検出力** |
|---|---|---|
| 0.5（中くらい） | 63 | **42%** |
| 0.6 | 44 | 56% |
| 0.7 | 32 | 70% |
| 0.8（大きい） | 25 | **81%** |
| 1.0 | 16 | 94% |

**各群 25 人で 80% の検出力が出るのは d ≈ 0.8 以上**。つまりこの研究は
「大きい効果なら見つかる、中くらいの効果は半分以上見逃す」設計になる。
これは失敗ではなく、**事前に分かっている制約**。

### 50 人を最大限に使うための 4 つの手当て

**① 主要評価項目を 1 つに絞る。**
客観指標の `depth_in_range_pct`（深さ 5〜6 cm の割合）を主要評価項目に置き、
残りはすべて副次・探索的にする。2 つ立てるだけで Bonferroni 補正により
検出可能な d が 0.79 → 0.87 に上がってしまう。

**② ANCOVA で共変量を入れる。**
CPR 経験の有無と VR 経験を共変量にする。相関が r≈0.5 あれば検出可能な d は
0.79 → 0.69 まで下がるが、ベースライン自己効力感を失ったぶん、
実際の相関はもっと低い可能性が高い。**解析計画に事前に書いておくこと。**

**③ 層別ランダム化を厳密に。**
CPR 経験あり／なしの各層で、A と B をきっちり半々に割り付ける。
群間で経験者の比率がずれると、それ自体が誤差になる。

**④ p 値だけでなく効果量と信頼区間を必ず報告する。**
n が小さいときの「有意差なし」は情報量がほとんどない。
点推定と 95% CI を出せば「効果があるとしてもこの範囲」という形で結論が書ける。

> 逐次明细（`compressions.csv`）がここで効いてくる。深度 SD や学習曲線は
> 平均値より効果量が大きく出やすく、**この設計で最も望みがある指標**。
> 詳しくは [objective_measures.md](objective_measures.md)。

**参加者 ID**：`P01`〜`P50`。群（A/B）は ID に埋め込まず、フォームの P2 と
Unity 側の `session_config.json` の両方に記録する。
ID と実名の対応表はオフラインで保管し、フォームには一切入れない。

## SUS スコア（0〜100）

標準の SUS は 1〜5 の 5 件法が前提で `(奇数−1) + (5−偶数)` の合計 × 2.5。
本研究は 0〜10 にそろえたので、線形変換（`x₅ = 1 + 0.4·x₁₀`）を代入すると畳めて：

```
SUS = 50 + (奇数項の合計 − 偶数項の合計)      ※ 各項 0〜10
```

列 `SUS1`〜`SUS10` が B〜K 列にあるとして：

```
=50 + (B2+D2+F2+H2+J2) - (C2+E2+G2+I2+K2)
```

全部「最良」なら 100、全部「最悪」なら 0（確認済み）。

> **これは已验证的 SUS ではない。** 回答形式を変えた時点で「68 = 平均」などの
> 常模との比較は根拠を失う。論文には「SUS の 10 項目を 0〜10 の評価尺度に改変し、
> 0〜100 に線形変換した」と明記し、文献値との直接比較はしない。
> **A 群と B 群の差を見るぶんには問題ない**（同じ尺度で測っているため）。

## NASA-TLX（Raw TLX, 0〜100）

```
=AVERAGE(TLX1:TLX6)*10
```

重み付けなしの Raw TLX。正式な重み付け版（ペア比較 15 回）は負担が大きく、
VR 研究では Raw TLX が一般的。論文には「Raw NASA-TLX を用いた」と明記する。

## 逆転項目

SUS の偶数項（SUS2・4・6・8・10）と HP7 は逆転項目。
尺度得点を作るときは `10 − 回答` にしてから合計する。

## 分析の見取り図

**被験者間なので検定はすべて独立標本**（t 検定 / Mann-Whitney U）。
事前アンケートを廃止したので、対応のある検定を使う場面は無い。

| 問い | 使うデータ | 検定（目安） |
|---|---|---|
| 振動で使いやすさは上がるか | SUS（A 群 vs B 群） | 独立標本 t 検定 / Mann-Whitney U |
| 振動で大変さは増えるか | Raw TLX | 同上 |
| 振動でリアルさは上がるか | PR1〜PR8 | 同上 |
| 振動で自信は高くなるか | SE 合計（体験後の水準） | 同上 |
| 不快症状に群差はあるか | SSQ 合計 | 同上（安全性の確認） |
| CPR 経験で効果はちがうか | EXP0（あり／なし）× 群 | 二元配置分散分析（どちらも被験者間） |
| 振動そのものの評価 | HP1〜HP8（**B 群のみ**） | 記述統計、または中央値 5 との一標本検定 |
| 振動の強さは適切だったか | HP9（**B 群のみ**） | \|HP9 − 5\| の記述統計 |

> **参加者は 50 人（各群 25 人）。** 80% の検出力が出るのは d ≈ 0.8 以上で、
> d = 0.5 の効果は 42% しか拾えない。主要評価項目は 1 つに絞り、
> 残りは探索的として報告すること。
>
> 有意差が出なかった項目について「差がない」と書かないこと——
> この n では「効果がない」と「検出力が足りない」が区別できない。
> 効果量と 95% 信頼区間を出して「あるとしてもこの範囲」という形で述べる。
