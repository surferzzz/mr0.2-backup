## 0. 实验设计（问卷结构由此决定）

| 項目 | 設定 |
|---|---|
| 条件 A | 画面の表示だけ（深さ・速さを HUD に表示、グローブの振動 OFF） |
| 条件 B | 画面の表示＋手の振動（浅い／ちょうどよい／深すぎ の強さの違い、リズム振動、AED の通電感） |
| 设计 | **被験者間（between-subjects）**：1 人は A か B のどちらか一方だけを体験する |
| 割付 | **CPR 経験の有無で層別**し、各層の中で A 群・B 群にランダムに振り分ける |
| 順序効果 | なし（1 人 1 条件なので、カウンターバランスも休憩も不要） |

**被験者間にした帰結**：A/B を直接くらべる質問紙（旧 Form 3）は成立しない
——どちらか一方しか体験していない人に「どちらが良かったか」は聞けない。
群の差は、事後アンケートの各尺度を**独立標本**で比べて見る。

**代价是样本量**。被験者内なら同じ人の中で差を取れるので個人差が相殺されるが、
被験者間では個人差がまるごと誤差に乗る。

### 参加者 50 人（各群 25 人）でできること

両側 α=.05・検出力 0.8 を基準にすると：

| 効果量 d | 必要な人数／群 | **各群 25 人での検出力** |
|---|---|---|
| 0.5（中くらい） | 63 | **42%** |
| 0.6 | 44 | 56% |
| 0.7 | 32 | 70% |
| 0.8（大きい） | 25 | **81%** |
| 1.0 | 16 | 94% |

**各群 25 人で 80% の検出力が出るのは d ≈ 0.8 以上**。つまりこの研究は
「大きい効果なら見つかる、中くらいの効果は半分以上見逃す」設計になる。

これは失敗ではなく、**事前に分かっている制約**。やるべきことは二つ：

1. 効果が大きいと見込める指標を**主要評価項目に選ぶ**（下記）
2. 中くらい以下の指標は**探索的**と宣言し、有意差が出なくても
   「差がない」とは書かない（検出力不足と区別がつかないため）

### 50 人を最大限に使うための 4 つの手当て

**① 主要評価項目を 1〜2 個に絞る。**
リアルタイムのフィードバック機器が圧迫の深さの適切さに与える効果は、
先行研究でも大きめに出やすい。客観指標の `depth_in_range_pct` を主要評価項目に置き、
残りはすべて副次・探索的にする。10 個も主要評価項目を立てると多重比較の補正で
検出力が消し飛ぶ。

**② ANCOVA で共変量を入れる。**
事前の自己効力感（SE 合計）や CPR 経験を共変量にすると、結果と r≈0.5 の相関があれば
誤差分散が 25% 減り、**検出可能な d が 0.79 → 0.69 に下がる**
（d=0.5 での検出力も 42% → 53%）。ひと手間で効く。

**③ 層別ランダム化を厳密に。**
CPR 経験あり／なしの各層で 25 人ずつきっちり半々に割り付ける。
群間で経験者の比率がずれると、それ自体が誤差になる。

**④ p 値だけでなく効果量と信頼区間を必ず報告する。**
n が小さいときの「有意差なし」は情報量がほとんどない。
点推定と 95% CI を出せば、「効果があるとしてもこの範囲」という形で結論が書ける。

> 逐次明细（`compressions.csv`）がここで効いてくる。深度 SD や学習曲線は
> 平均値より効果量が大きく出やすく、**この設計で最も望みがある指標**。
> 詳しくは [objective_measures.md](objective_measures.md)。

>
> Google Forms の分岐は「ラジオ／プルダウンの回答 → 指定セクションへ移動」でしか作れません。
> P2（条件）で分岐させると、SUS・TLX・リアルさまで A 用と B 用に二重化する羽目になります。

> **推奨：分岐を使わず、セクション 5 を「任意回答」にする。**
> セクション 5 の冒頭に「B（振動あり）を体験した人だけ答えてください」と書き、

> 集計時は `P2 = A` の行で HP 列が空になるだけなので、分析上まったく問題ない。
> 分岐のつけ間違いで回答が丸ごと飛ぶ事故がないぶん、こちらが確実です。
>
> どうしても厳密に分けたい場合は、**フォームを 2 本に分ける**（体験後_A／体験後_B）。
> 回答は別シートになるので、集計時に縦結合してください。

## 題目作成のコツ

- **リッカート尺度は必ず「グリッド（選択式）」で作る。** 1 項目ずつラジオで作ると被试要滚十几屏，疲労回答が増える。
- **グリッドは「各行で 1 つの回答を必須にする」を ON。** 漏答が構造的に防げる。
- **質問文の先頭に短いコードを付ける**（例：`SUS3. このシステムは簡単に使えた`）。
  Sheet の列名は質問文そのままなので、コードがないと列が特定できず集計が地獄になる。
- **双极量表（HP9 振動の強さ）は単独の「均等目盛」で作る。** 他のグリッドに混ぜない。
- **分岐（セクションに移動）はラジオ／プルダウンのみ。** チェックボックスやグリッドには付けられない。
- 分岐を使ったセクションの末尾は、**「次のセクションに進む」の行き先を必ず確認する**。

## 回答の集計（Sheets）

「回答」タブ → 緑のシートアイコン → **スプレッドシートにリンク**。3 本のフォームを 1 つのスプレッドシートの
別タブにまとめると、参加者ID で `VLOOKUP` / `QUERY` できて楽。

### SUS スコア（0〜100）— ★ 0〜10 に変えたので式も変わった

標準の SUS は 1〜5 の 5 件法が前提で、`(奇数−1) + (5−偶数)` の合計 × 2.5 で 0〜100 にする。
本研究は尺度を 0〜10 にそろえたので、その式はそのままでは使えない。

0〜10 の回答を 1〜5 に線形変換（`x₅ = 1 + 0.4·x₁₀`）してから標準式に入れると、きれいに畳めて

```
SUS = 50 + (奇数項の合計 − 偶数項の合計)      ※ 各項 0〜10
```

列 `SUS1`〜`SUS10` が B〜K 列にあるとして：

```
=50 + (B2+D2+F2+H2+J2) - (C2+E2+G2+I2+K2)
```

全部「最良」なら 100、全部「最悪」なら 0 になる（確認済み）。

> **ただし、これは已验证的 SUS ではない。** 回答形式を変えた時点で、
> 「68 = 平均」のような常模（norm）との比較は根拠を失う。論文には
> 「SUS の 10 項目を 0〜10 の評価尺度に改変して用い、0〜100 に線形変換した」と明記し、
> 文献値との直接比較はしないこと。**A と B の差を見るぶんには問題ない**
> ——同じ尺度で同じ人が両方に答えているため。
>
> 文献と比べられる SUS がどうしても要るなら、SUS の 10 項目だけ 1〜5 に戻すしかない。

### NASA-TLX（Raw TLX, 0〜100）

```
=AVERAGE(L2:Q2)*10
```

6 項目を重み付けせず平均する「Raw TLX」。正式な重み付け版（ペア比較 15 回）は被试负担大，
VR 研究では Raw TLX で報告するのが一般的です。論文には「Raw NASA-TLX を用いた」と明記すること。

### 自信の変化

```
事前 SE 合計：=SUM(Form1!SE1:SE6)
事後 SE 合計：=SUM(Form2!SE1:SE6)
変化量      ：=事後 − 事前
```

条件 A の変化量と条件 B の変化量を、`参加者ID` で突き合わせて比較する。

### 分析の見取り図

| 問い | 使うデータ | 検定（目安） |
|---|---|---|
| 振動で使いやすさは上がるか | SUS（A 群 vs B 群） | **独立標本 t 検定 / Mann-Whitney U** |
| 振動で大変さは増えるか | Raw TLX（A 群 vs B 群） | 同上 |
| 振動でリアルさは上がるか | PR1〜PR8（A 群 vs B 群） | 同上 |
| 自信は上がるか（群ごと） | SE 合計（事前 → 事後） | **対応のある** t 検定（ここだけ同一人物内） |
| 自信の伸びに群差はあるか | SE の変化量（事後 − 事前） | 独立標本 t 検定、または事前値を共変量に ANCOVA |
| CPR 経験で効果はちがうか | EXP0（あり／なし）× 群 | 二元配置分散分析（**どちらも被験者間**） |
| 振動そのものの評価 | HP1〜HP8（B 群のみ） | 記述統計、または中央値 5 との一標本検定 |
| 振動の強さは適切だったか | HP9（B 群のみ） | \|HP9 − 5\| の記述統計 |

> **参加者は 50 人（各群 25 人）。** 80% の検出力が出るのは d ≈ 0.8 以上で、
> d = 0.5 の効果は 42% しか拾えない。上の表のうち**主要評価項目は 1〜2 個に絞り**、
> 残りは探索的として報告すること。共変量を入れた ANCOVA にすると
> 検出可能な d が 0.79 → 0.69 に下がる。詳しくは「0. 实验设计」を参照。
>
> 有意差が出なかった項目について「差がない」と書かないこと——
> この n では「効果がない」と「検出力が足りない」が区別できない。
> 効果量と 95% 信頼区間を出して、「あるとしてもこの範囲」という形で述べる。
